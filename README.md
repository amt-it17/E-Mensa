# E-Mensa – Web Development Project

## 📌 Project Overview

E-Mensa is a web development project created as part of my Computer Science studies at FH Aachen University of Applied Sciences.

The project focuses on building a structured and user-friendly website using HTML and CSS.

## 💻 Technologies Used

* HTML5
* CSS3
* GitHub
* phpStrom

## 🚀 Features

* Structured web pages using HTML5
* Responsive layouts using CSS
* Navigation between different sections
* HTML forms with different input elements
* Tables, images, and hyperlinks
* Basic web design and styling

## 🎯 Learning Objectives

The main objectives of this project were to:

* Improve my HTML and CSS programming skills.
* Understand the structure of modern websites.
* Apply web development concepts in practice.
* Develop problem-solving skills through practical programming exercises.

## 👩🏽‍💻 My Contribution

I worked on the implementation of the website, including its HTML structure, CSS styling, navigation, and forms.
